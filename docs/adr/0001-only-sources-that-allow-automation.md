# Only use sources whose terms allow automated access

The richest sources of part-time freelance data work (Upwork, LinkedIn, Indeed, Wellfound, Fiverr, Contra, Freelancer.com) explicitly forbid scraping, bots, or automated applying in their terms. We read only from sources that permit automation: v1 is HN "Who's Hiring" (Algolia API), Himalayas, Jobicy, RemoteOK, and Remotive. This costs volume, especially of genuinely part-time gigs, but keeps Aaron's accounts and reputation safe. A marketplace may be added only through an officially approved API use case.

## Consequences

- Fewer part-time listings than a marketplace would yield; the 5-per-week target is measured for two weeks before deciding on phase 2 (direct outreach).
- We Work Remotely and Working Nomads are excluded until their terms can be confirmed.
